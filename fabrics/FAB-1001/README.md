## Installer notes

- The fabric blocks all light, but light can still leak around the edges. Recommend side channels or a cassette for true room darkening.
- The white backing faces the window so the house looks uniform from the street.
- Handle rolls carefully. Blackout coatings can crease and show lines if folded.
