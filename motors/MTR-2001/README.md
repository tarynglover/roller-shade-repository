# MTR-2001: VTi® Celtic RF AC Motor, Electronic Limits

![VTi Celtic RF AC motor](photo.jpg)

A hardwired 110V AC tubular motor with RF remote control. Up and down stopping points (limits) are set electronically with the remote, so no adjustment screws are needed. This is our standard motor for medium-size shades where power is available at the window.

## Installer notes

- Requires power at the window. Hardwiring should be done by a licensed electrician.
- After mounting, pair the motor to the remote, then set the upper and lower limits with the remote.
- Check the shade weight before quoting. Heavy blackout fabric on a wide shade can exceed 22 lb.
- This is the replacement for discontinued MTR-2002. See [Discontinued Items](../../DISCONTINUED.md).
