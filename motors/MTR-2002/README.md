## Installer notes (service only)

- Limits are adjusted with the screws on the motor head. Turn toward + to extend travel, toward − to shorten it.
- When replacing with MTR-2001, the wiring and tube size are the same. The only change is that limits are set with the remote.
- Note the install date and room on the service ticket so the customer record stays current.
